# 怪兽吃我的公寓 · H5 核心玩法 Demo

以用户指定的 **Super Monsters Ate My Condo（2024 重制版）** 为目标，用 Three.js + H5skill 制作的可玩研究 Demo。核心操作和基础合成链已落地；公开资料不足以确认所有高级奖励条件，因此本版本**不宣称完整数值或全部规则已经 1:1 验证**。

## 打开

- 在线试玩：[GitHub Pages](https://kamimaomao.github.io/monster-condo-demo/)。
- `delivery/怪兽公寓-demo.html`：自包含版本，双击打开即可，无 CDN、无需安装。
- `npm install && npm run dev`：本地开发；默认 `http://localhost:5173/`。
- `npm run build`：输出静态网页到 `dist/`，同时生成单文件与 GitHub Pages 的 `docs/index.html`。
- `npm test`：运行规则回归检查。

鼠标或手指左右拖出公寓。也可点选楼层后按方向键。第一次有效滑动才开始计时。

包含两分钟挑战、无限练习、暂停/继续、重开、结算、可开启的合成音效。**连锁演示**只替换初始塔，随后使用与正常游戏相同的匹配代码，连续产生铜、银、金、钻石与 Mega Zone。

## 消除规则核对

以下序列按从塔底到塔顶排列。核心匹配层与附带清除层分开计算，普通异色不能被跳过。

| 情况 | Demo 判定 | 证据强度 |
|---|---|---|
| 红 / 红 / 蓝 / 红 | 不自动匹配；抽走蓝以后红三连 | 2024 官方基础玩法 |
| 蓝 / 铜 / 蓝 / 铜 / 蓝 | 三个蓝变一个铜，旧铜保留，接着三个铜变银 | 旧版明确实例；2024 官方视频确认同类的跨银匹配和银层保留 |
| 普通同色 ≥3 | 产生一个铜层；上层落下后继续匹配 | 官方基础玩法 |
| 铜×3 → 银、银×3 → 金、金×3 → 钻石 | 每次一个基础升级层，绿能力可翻倍 | 官方专题、2024 教程与旧版资料 |
| 钻石×3 | 进入 Mega Zone | Apple 官方专题 |
| 对应在场怪兽颜色被合成 | 该怪兽换班 | 2024 指南及旧版实测 |
| 红 / 红 / 混凝土 / 红 | 三红合成，混凝土附带清除 | 旧版规则；新版此边界仍待补清晰画面 |
| 三个混凝土 | 合成猫，不直接判死局 | Super 旧版资料 |
| 时钟 / 储蓄罐 / 时钟 | 混合粉色三连变倍率层 | Super 旧版详解 |
| 时钟、储蓄罐、倍率层 | 直接喂食或组合收集，分别加时间、金币、基础倍率 | Super 旧版详解 |
| 金属夹层 | 保留 | 2024 官方片 8.55–8.65 秒及旧版实例 |
| 猫、混凝土、粉色特殊层夹层 | 随组合消耗 | 旧版机制；官方片可见猫参与跨银匹配 |

**2024 官方视频的直接观察**：8.55–8.65 秒的区域包含黄层、猫、两层银、另一黄层；黄色同时白化，银层仍在。该镜头能证明跨金属匹配，因特效遮挡不能证明猫的精确增产数量。原片为 `references/official-trailer.mp4`。

## 重建假设与范围

这些参数集中在 `src/model.js` 的 `RULES`，不应误认为来自原作代码：

- 时钟暂按第三次及之后的连续匹配生成；旧资料描述有歧义，**尚未确认原作阈值**。
- 五层以上匹配追加储蓄罐来自旧版记载，新版未取得完整验证。
- 每只参与匹配的猫暂额外增加一个升级层；数量与绿能力叠加顺序待核。
- 普通色穿过钻石、不同高级特殊层组合、边缘连续特殊层的收集范围，尚需新版逐条实测。
- 初始 14 层、掉落配色、基础分、怒气、能力时长、Mega 的 12 秒/100 倍与免怒表现均为重建参数。
- 连锁窗口按公开指南采用 2 秒，未从原作配置提取。
- 蓝能力只稳定塔及加倍特殊奖励；不作为全局双倍分。Mega 不隐式开启四只怪兽能力。
- 高塔用重力、回弹、倾斜模型重建，尚非原作刚体求解器。塔在连锁结束后补足；原作的持续供楼节奏未完全复刻。

未做炸弹、酸液、核弹、狗、帽子、成长等级、开局道具、转盘、排行榜和商业化系统。普通 H5 Demo 没有下载跳转。

## 动效与美术

Three.js 实时渲染有厚度和侧面的楼层。匹配先白化约 0.28 秒，再压缩；横向同色宽光带、光环、碎屑、分数光迹同时出现。连续升级加强震屏、金光与倾斜 COMBO 字样；上层重力下落回弹；划出楼层飞向怪兽并触发吞食动作。

时序来自官方片观察，非程序参数。四只怪兽是参照官方造型编写的可编辑 SVG；楼层纹理由 Canvas 绘制。未取得原作分层美术、音源或代码；音效由 Web Audio 合成。

## 文件

- `src/model.js`：匹配、消耗/保留、升级、喂食、收益、时间与能力。
- `src/scene.js`：Three.js 楼层、运动、光带、粒子与分数飞行。
- `src/main.js`：输入、动画状态、HUD、模式、暂停与结算。
- `src/monsters.js`：四只怪兽 SVG。
- `tests/model.test.js`：边界和回归断言；测试通过不等于证明原作语义。
- `references/`：官方素材、来源与观察记录。
